# BioLM_taxonomy_promoter

This repository contains the codes for two tasks using BioLMs:
* Codes we used to test if taxonomy of Type I methanotroph genomes can be classified using protein language model (pLM)
* Codes we used to predict promoter expression on the [Random Promoter DREAM Challenge 2022](https://github.com/de-Boer-Lab/random-promoter-dream-challenge-2022) using genome language model (gLM)

Data of genome sequence and protein sequences are not included in the repositories and have to be downloaded separately.
